🚃 D2 市區鐵道串聯（押上→淺草→人形町→飯田橋→秋葉原→上野→押上）

第二天行程橫跨都營淺草線、日比谷線、東西線、JR 中央總武線、JR 山手線／京濱東北線與銀座線。

  • 押上 → 淺草（09:21–09:24）：都營淺草線特急（往京急久里濱等方向，2 站約 3 分鐘，¥180 / IC ¥178）。
  • 淺草 → 人形町（14:35–14:41）：都營淺草線（約 5 分鐘一班，¥180）。
  • 人形町 → 茅場町 → 飯田橋（15:52–16:12）：日比谷線轉東西線（¥180）。
  • 飯田橋 → 秋葉原（17:18–17:25）：JR 中央總武線（¥160）；秋葉原 → 御徒町（18:45–18:47）：京濱東北·根岸線或山手線（¥160）；上野 → 淺草 → 押上：銀座線轉都營淺草線（¥290）。

🚆 D3 春日部往返與新宿路線

第三天一早從押上出發前往春日部，傍晚經大宮轉乘 JR 湘南新宿線前往新宿。

  • 押上 → 春日部（09:13–09:55）：東武伊勢崎線 [晴空塔線] 急行（¥490）。
  • 春日部站東口 → 幸松第二公民館（16:16–16:25）：搭公車（¥180），前往春日部車站搭車。
  • 春日部 → 大宮 → 新宿（16:48–17:48）：東武野田線急行至大宮，轉乘 JR 湘南新宿線至新宿（¥860 / IC ¥852）。

✈️ 機場與住宿銜接提醒

D1 抵達成田機場後前往押上 WISE OWL NEST；D3 傍晚抵達 Hotel Livemax 新宿歌舞伎町。

  • D1 入境與接駁（16:55–19:30）：完成出境／入境流程後前往住宿，預留 6 人同行與行李移動時間。
  • D6 返台航班：請依最終電子機票再次核對出發日期、起飛時間與成田航廈。
